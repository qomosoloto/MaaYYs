# Changelog

本文件记录 MaaYYs fork 的重要二次开发变更。

## [Unreleased]

### Added

- 新增独立的 `自动寮突破 V2（实验版）` 任务入口，原版自动寮突破保持不变。
- `GuildBarrierTargetRecognition` 支持任务自定义目标布局和日志前缀。

### Changed

- V2 在战斗结算后按突破列表实际就绪状态推进，移除正常场间流程约 18 秒的固定组合等待。
- V2 仅在玩家名与进攻按钮成对识别成功后记录目标，并直接点击同一次识别返回的按钮框。
- V2 移除进攻前的旧末尾玩家重复计数，避免未进攻时误判已攻破并循环关闭、重进突破界面。
- V2 不再将进攻弹窗背景中的“击败次数”误判为已经返回目标列表，并将进攻后的战斗等待上限扩展到 600 秒，修复胜利结算时任务超时失败。
- V2 保留常规结算点击，并在 MuMu 多显示输入无响应时动态定位阴阳师所在 Android display；OCR 仍命中结算提示时通过指定 display 的 ADB Shell 限频补点，结果节点状态窗口保持 60 秒。
- V2 保留已攻破短暂提示、实际进攻后的重复目标判断和重新进入阴阳寮突破的异常恢复流程。

### Fixed

- 修复 V2 战斗结算补点三次未生效后恢复节点永久耗尽的问题；补点改由 60 秒状态窗口和 OCR 限频控制，并在日志中输出 Android display、viewport 与实际点击坐标。
- 修复 V2 结算点击落入加成说明弹窗而无法继续的问题；常规点击收窄到底部安全带，指定 display 的 Shell 补点改为逻辑画面高度 95% 处，并经两个 MuMu 实例验证。
